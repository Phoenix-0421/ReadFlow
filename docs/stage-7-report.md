- 难点 3：校验与容错放在哪一层，解法是"表单严格校验 / 领域信任入参 / 存储层修复脏数据"的三层分工；并注明**领域层不再二次钳制**这个取舍。

**4. 项目局限** —— 6 条如实列出：只存本地、无导入导出、在线搜索不可用、没有自动化测试、没有 ErrorBoundary、几个功能小缺口。

## 七、尚未解决的问题

### 7.1 需要你决定的两件事（我按约定没动）

**① Git 里第二～七阶段的改动全部未提交。**

`git status` 显示 **10 个修改 + 8 个新增**文件处于未提交状态，而远程已经有仓库（`origin/main`，只有 2 个提交"基本框架"）。也就是说：**如果这台机器出问题，二到七阶段的全部工作都会丢。**

按协议我**没有执行任何 `git add / commit / push```。建议你自己确认内容后提交，比如：

```bash
git add -A
git commit -m "完成阅读管理核心功能：书架、进度、笔记、首页看板"
git push
```

**② 根目录的 `.readflow-backup-20261014-153113/` 是第三阶段改写 Vite 模板文件前做的备份。**

里面是模板原始版本的 `index.html / package.json / tsconfig*.json / src/{App,main}.{tsx,css}`。它已经被 `.gitignore` 忽略（不会进仓库），但留在本地会显得目录不干净。**要删的话你确认一下**，我没有擅自删。
